# Runtime dependencies named by the locked architecture.  Model weights and
# whisper.cpp are installed separately and are never vendored in this repo.
#
# Any --hash below puts pip into hash-checking mode, which then demands a hash
# for every distribution it installs -- transitive dependencies included.  The
# complete closure of onnxruntime and websockets is therefore pinned here.
#
# Python: CPython 3.12 exactly, not a floor.  onnxruntime 1.20.1 publishes no
# sdist and no pure-Python wheel, so pip must take an ABI-tagged binary wheel;
# only the cp312 ones are hashed here.  On 3.11 or 3.13 pip selects a cp311 or
# cp313 wheel instead, finds no matching hash and aborts the install.
#
# Platforms: Linux x86_64 (manylinux, glibc >= 2.28) and macOS arm64 (>= 13.0,
# via universal2).  Linux aarch64 is deliberately NOT covered -- the deploy
# target is x86_64 Ubuntu 24.04.  Upstream aarch64 wheels do exist, so this is
# a documented scope limit rather than an upstream gap.  Windows and musl are
# out of scope for the same reason.
#
# Regenerate hashes from the PyPI JSON API, e.g.
#   https://pypi.org/pypi/onnxruntime/1.20.1/json
